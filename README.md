## Como organizo o desenvolvimento

- **Problema antes da ferramenta:** entender o fluxo de trabalho e suas restrições.
- **Código rastreável:** separar aplicação, configuração, dados e evidências.
- **Automação supervisionada:** ações sensíveis exigem controle e autorização.
- **Entrega verificável:** distinguir protótipo, demonstração e operação real.
- **Privacidade por padrão:** sem credenciais ou dados de clientes nos materiais públicos.
